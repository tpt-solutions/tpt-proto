# Provenance

This directory documents the provenance and clean-room status of tpt-proto.

- `decisions.md` — log of major implementation decisions and their rationale.
- `ai-policy.md` — policy and process for AI-assisted contributions.
- `test-vectors.md` — origin and derivation of test vectors.

tpt-proto is an independent clean-room implementation. It is not an official
Protocol Buffers implementation, and its code is written from the public
specification (`spec.txt`) and published standards, not from any other
implementation's source.
